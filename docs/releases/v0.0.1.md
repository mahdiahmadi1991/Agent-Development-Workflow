# Release v0.0.1

Release date: 2026-03-13

## Summary
Initial public baseline for Codex Onboarding VS Code extension infrastructure and governance-aligned behavior.

## Behavior Impact
- Introduces managed onboarding lifecycle commands: install, remove, repair.
- Enforces non-destructive writes and fail-fast drift behavior for managed files.
- Adds structured operation logging and post-install guidance flow.

## Migration Guidance
- No migration required for fresh installs.
- For existing experimental setups, run `Repair` to rebuild managed state before further updates.
