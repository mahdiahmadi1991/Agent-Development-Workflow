# Working Agreement

This file records standing rules agreed in this project.

## Active Rules
1. This repository is for Codex onboarding only.
2. Artifacts are English-only.
3. Governance must be domain-agnostic and reusable.
4. Rule strictness is dynamic by policy risk.
5. Consumer exceptions must be implemented via overrides, not by editing managed core files.
6. No commit/push actions are allowed without explicit user approval.

## Update Protocol
When a new permanent rule is agreed:
1. Add it to this file.
2. Reflect it in `AGENTS.md` when it changes agent behavior.
3. Update related docs in `docs/governance/`.
