# Environment Support Matrix

## Goal
Provide a clear, always-current view of where extension behavior is supported and tested.

## Supported Runtime Targets
- VS Code on Windows
- VS Code in WSL context
- VS Code on Linux
- VS Code on macOS

## Test Coverage Status
- Windows: required CI lane
- Linux: required CI lane
- macOS: required CI lane
- WSL: required dedicated validation lane

## Out-of-Scope (Current Phase)
- Remote-SSH runtime
- Dev Containers runtime

## Governance Requirement
This matrix must be updated in the same cycle as any support-policy change.
