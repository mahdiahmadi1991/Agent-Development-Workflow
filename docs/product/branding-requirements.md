# Branding Requirements

## Goal
Define extension identity assets and publication copy requirements.

## Locked Brand Direction
- Product name: `Codex Onboarding`
- Visual style: dark neutral base (`#0a0a0a`) with OpenAI-aligned accents (`#ffffff`, `#10a37f`)
- Messaging style: precise, operational, no ambiguous automation claims

## Required Assets
- Marketplace icon (primary): `packages/vscode-extension/assets/branding/icon-128.png`
- Small-size icon variant: `packages/vscode-extension/assets/branding/icon-64.png`
- Vector mark source: `packages/vscode-extension/assets/branding/icon-mark.svg`
- Short description (package): managed onboarding with safe install/repair/remove lifecycle
- Long description (README): behavior contracts, safety model, and release guidance
- Marketplace keywords: codex onboarding/governance/safe-managed-files scope

## Copy Constraints
- Must clearly communicate managed-file ownership model.
- Must clearly communicate non-destructive and drift-stop behavior.
- Must avoid ambiguous promises about editing user-owned files.
- Must avoid claims outside current scope (for example multi-agent support).

## Quality Criteria
- Consistent visual identity across icon and documentation.
- Clear and concise product value proposition.
- Technical behavior summary aligned with living spec.
- Marketplace metadata must pass checklist in `docs/product/marketplace-readiness-checklist.md`.
